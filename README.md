# ECO STRUCT - Dashboard Financiero

Dashboard interactivo de análisis financiero para **Constructive Ecosen Spain 2.3**.

## Funcionalidades

- **Resumen General**: KPIs, gráficos de donut, margen por proyecto, certificación vs coste
- **Obras**: Tabla detallada por proyecto con análisis de margen y donuts individuales
- **Prorrateo Gastos**: Distribución de gastos generales y vehículos por proyecto
- **Mano de Obra**: Horas y costes por proyecto
- **Facturas por Obra**: Análisis de facturas por proveedor y proyecto
- **Certificaciones**: Certificaciones por proyecto
- **Exportar PDF**: Informe financiero completo o por obra individual
