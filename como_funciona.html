🏢 Dashboard ECO STRUCT - Como Funciona

Explicación sencilla del flujo de datos

PASO 1

📁 Tú metes los datos en estos 3 archivos

Están en la carpeta dashboard/. Cuando quieras actualizar algo, solo cambias aquí:

📄
ECO_STRUCT_-_Workspace_Gastos.csv
Facturas de Billdin (gastos directos, gastos generales, vehículos)
📊
CERTIFICACIONES POR MESES 2026.xlsx
Certificaciones de cada obra por mes
👷
GASTOS MANO DE OBRA POR MESES 2026.xlsx
Horas y coste de mano de obra por obra y mes
⬇️
Dales doble clic a actualizar.bat
PASO 2

🐍 Python lee los 3 archivos

⚙️
extraer_datos.py
Lee el CSV y los dos Excel, calcula totales, prorrateos, y guarda todo en un JSON
💡 Python es el "trabajador" que procesa los datos. No necesitas saber programar, solo ejecutarlo.
⬇️
PASO 3

📦 Se crea un archivo JSON (el "almacén")

🗄️
datos_ecostruct.json
Contiene TODOS los datos calculados: certificaciones, gastos, prorrateos, márgenes, facturas... Todo en un solo archivo que los dashboards leen
⬇️
PASO 4

🎨 Dos scripts crean los dashboards

1️⃣
regenerar_dashboard.py
Lee el JSON → crea el dashboard.html (V1 clásico)
2️⃣
regenerar_dashboard_v2.py
Lee el JSON → crea el dashboard_v2.html (V2 corporativo)
📊
crear_excel_completo.py
Lee los 3 archivos → crea el ECO_STRUCT_Datos.xlsx
⬇️
PASO 5

✅ Resultado: tus archivos finales

🌐
dashboard.html
Dashboard V1 clásico
🌐
dashboard_v2.html
Dashboard V2 corporativo
📊
ECO_STRUCT_Datos.xlsx
Excel con todas las pestañas
⬇️
PASO 6

☁️ Se sube a GitHub (internet)

🚀
subir_a_github.bat
Sube los archivos a GitHub para que los veas desde el móvil, tablet u otro ordenador en juanjosemas.github.io/dashboard

📋 Resumen en 3 líneas

  1. Tú cambias datos en los archivos de la carpeta dashboard/
  2. Das a actualizar.bat y Python hace todo el trabajo solo
  3. Se actualizan los 2 dashboards + Excel + GitHub
actualizar.bat = extraer datos → crear dashboards → crear Excel → preguntar si subir a GitHub
